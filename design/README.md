# Logo and favicon

The GNIS-LD wordmark and favicon are generated by the scripts in this folder. "LD" is drawn as a triangulated mesh: nodes are placed on the outline of each letter and inside it, and the Delaunay edges that lie inside the letter are kept.

| File | Generates |
|---|---|
| `logos2.py` | The letter outlines and the mesh. It is imported by the other two scripts. Run on its own, it writes `logos-v2.html`, a sheet of the mesh and constellation sketches. |
| `logo.py` | `export/logo.svg` and `export/logo-dark.svg`, and the preview page `logo.html` |
| `favicon.py` | `export/favicon.svg` and the preview page `favicon.html` |
| `render-favicons.sh` | `export/favicon-16.png`, `-32.png`, `-180.png` and `-512.png`, rendered from `export/favicon.svg` with Chrome |

`logo.py` places the hyphen and "LD" from the measured width and cap height of "GNIS", which are read from `measure.json`. `measure.html` measures them in a browser. Open it in Chrome after changing the font, size, weight or tracking of "GNIS", and save the JSON it shows to `measure.json`.

## Rebuilding

The scripts need shapely. From the `gnis-ld.org` folder:

```sh
uv run --no-project --with shapely python design/logo.py
uv run --no-project --with shapely python design/favicon.py
design/render-favicons.sh
```

Then copy the files the website uses into `lib/webapp/_images/`:

| Export | Website file |
|---|---|
| `export/logo.svg` | `gnis-ld-logo.svg` (header) |
| `export/logo-dark.svg` | `gnis-ld-logo-dark.svg` (footer) |
| `export/favicon.svg` | `favicon.svg` |
| `export/favicon-16.png`, `export/favicon-32.png` | `favicon-16.png`, `favicon-32.png` |
| `export/favicon-180.png` | `apple-touch-icon.png` |

The mesh's interior nodes are jittered by a seeded random generator, so a rebuild produces the same files.

## Before production

"GNIS" is SVG text in the system font, so it renders differently where that font is missing. Set it in an open-licensed typeface and convert it to outlines, then measure that typeface with `measure.html`.
